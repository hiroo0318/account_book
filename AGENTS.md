# Project operating guide

One Codex normally owns planning, execution, and proportional self-checking for this project.

Do not create standing agent teams, role splits, forced prompt chains, infinite review loops, or automatic handoffs. Use specialist or parallel work only for an independent, high-impact review; never to divide ordinary work.

Keep `.codex/PROJECT_CONTEXT.md` current as scope or implementation decisions change. Record only durable, consequential choices in `.codex/DECISIONS.md`.
